## 验收与协作约定

D 的验证包括可观察页面行为、客户端权限失败、重复/未知写入恢复、状态过期、真实代理与网络调用，以及工程空库迁移和健康/恢复检查。发布验收需使用可定位的应用/镜像版本；应用镜像回退不等于数据库可降级，业务迁移兼容性由对应 owner 明确后，D 才能按该范围演练。

沿用 Issue → 实施计划 → 负责人授权 → 独立分支 → 实现与验证 → PR → 非作者 Review → 合并的工作流。负责人已授权本轮 D 开发与文档更新；公共契约、生产权限及未决业务政策仍由对应负责人确认。AI技术评论不计为非作者人工Approve，CI成功也不等于已发布。

演示和测试使用合成账号/教室，不记录真实学生资料、令牌或密码。AI辅助分析、实现、测试、故障定位和文档；人类负责人负责需求取舍、验收和最终责任。代表性失败、修复及负对照见 [D交付说明](d-delivery-status.md) 和对应版本化验证记录。
