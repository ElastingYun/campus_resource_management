## 固定依据与最小范围

读取 E [#62](https://github.com/ElastingYun/campus_resource_management/pull/62) 的 `d310c5610ae66341a767244e000d8babb1142b08` 路由、schema 与身份/审计端口，E [#69](https://github.com/ElastingYun/campus_resource_management/pull/69) 的 `f5802f5685ee5625e7809204937735e31430caaf`，E [#74](https://github.com/ElastingYun/campus_resource_management/pull/74) 的 `9869ad0a322a57a5f2f04f866c43b01561263b4f` 开工说明，以及 C [#59](https://github.com/ElastingYun/campus_resource_management/pull/59) 的 `11ed32076ae96c756f2f246a29c23a5d0a9bd1df` 身份适配文档。

F-03 首个页面增量拟仅含“报修、我的工单列表、本人详情”。派单、维修开工、验收、评价及通知另列增量，不因存在候选接口就在页面开放操作。正式模式只使用服务端接口；独立原型若经确认使用合成数据，必须清楚标记。

| 已有接口 | 固定实现的可观察契约 |
| --- | --- |
| `POST /api/v1/m3/tickets` | `room_id` 正十进制 BIGINT 字符串，`description` 去首尾空白后 1～2000 字符，拒绝控制字符；`Idempotency-Key` 为 1～128 个可打印 ASCII 非空格字符；首次 201、同键同内容重放 200 |
| `GET /api/v1/m3/tickets?limit=20&offset=0` | 只读本人；limit 1～100、offset 非负；响应 `items/limit/offset`，当前没有 total，不编造总页数 |
| `GET /api/v1/m3/tickets/{ticket_id}` | UUID 工单 ID；响应 `id/room_id/description/status/created_at`；不把 404 推断为工单已撤销或维修已解除 |

浏览器中的教室 ID 始终是字符串，范围 1～9223372036854775807；不转成 JavaScript Number。故障描述按文本显示，不作为 HTML；令牌、密码和描述不进入运行日志。

## 页面验收草案

| 场景 | 验收要求 |
| --- | --- |
| 正常报修 | 使用当前可信会话及有效教室 ID；提交中禁用重复操作；201 或确认的同键 200 后显示真实工单 ID，再读取本人详情 |
| 输入边界 | 空白/超长描述、控制字符、非法或超 BIGINT 教室 ID 在发送前提示；仍由后端最终校验。E 当前拒绝换行，不能悄悄截断或改写描述后提交 |
| 未知结果 | 超时或响应丢失不能显示“未创建”；保留原主体、原键及原内容，只按明确恢复动作重放；取得 ID 后读取真实结果，不换键重发 |
| 键冲突 | 409 显示冲突并阻止误报成功；不同内容不能复用旧键。尚未知结果时不允许编辑后拿旧键提交 |
| 列表 | 加载、空列表、失败各有明确状态；limit/offset 与响应一致。满页可继续查询，短页结束，不把没有 total 的响应当成有总数 |
| 详情 | 显示原始状态的安全映射；未知状态显示未识别并停用未批准操作，不推断可开工或整室已恢复 |
| 认证与权限 | 401 清理过期会话；403 不开放额外按钮或数据；账号/令牌变化使旧读结果失效，旧主体未知写入不能作为新主体重放 |
| 缺少依赖 | 503 身份、房间资格、审计未配置或网络失败显示不可用，不回退合成成功；兼容 E `detail.code/message` 与 C 认证 `error` 包装 |
| 离页与隐私 | 未知提交结果离页前提示；避免持久化故障描述和令牌。跨刷新恢复策略须明确其存储与隐私约束后实施 |

后续实现需对正常、失败、边界、重复提交、晚响应与主体隔离做页面/客户端行为测试；选取有意义的负对照证明断言能捕捉错误。本轮文档不冒充这些测试已运行。
